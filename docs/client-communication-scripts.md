# Fiverr 客户沟通话术 — 邮件分类服务
### Client Communication Scripts (Email Classification Service)

> 用途:客户问准确率、发现分错、问不确定处理、对比 Gmail 标签时,直接复制对应段落。
> 心法:① 永远先亮"没删任何东西";② 道歉三连(抱歉+已修复+已记住)后马上给行动;③ 有数字报数字,没数字讲流程,绝不承诺 100%。

---

## 场景 1:客户问"能保证 100% 准确吗?"

**中文:**
说实话,任何邮件分类系统都没法保证 100% 准确——Gmail 自己的标签也经常分错。但我在设计上把"出错"的成本降到了最低:第一,永不删除你的任何邮件,分错的信也都在档案里,一键找回;第二,系统拿不准的邮件一律不动,会单独列出来给你决定;第三,规则完全按你的定义来,你每纠正一次,系统就记住一条,越用越准。我可以先在你的真实邮件样本上跑测试,把准确率数字给你看,满意了再全量处理。

**English:**
To be honest, no email classifier can guarantee 100% accuracy — even Gmail's own tabs get it wrong sometimes. But I've designed this so that when a mistake happens, it costs you nothing: 1) I never delete anything — every email stays in your archive, searchable and recoverable in one click; 2) emails the system isn't confident about are never touched — they're listed separately for you to decide; 3) the rules are built around your own definition of "important", and every correction you give makes it smarter. I can run a test on a sample of your real emails first and show you the accuracy numbers before we do the full mailbox.

## 场景 2:客户说"你把我的 XX 邮件分错了"(售后补救)

**中文:**
您说得对,这封确实分错了,抱歉给您添麻烦。请放心:邮件没有被删除,只是被归档,您现在就能在 All Mail 里找到它。我已经把它移回收件箱,并记成一条规则例子——以后同类的邮件都会按您的标准正确处理。方便的话,麻烦您再帮我扫一眼还有没有类似的,我一次性全部修正并更新规则。

**English:**
You're right, that one was misclassified — sorry about that. Good news: nothing was deleted, it was only archived, so you can find it in All Mail right now. I've moved it back to your inbox and added it as a rule example, so similar emails will be handled the way you want from now on. If you spot any others that look wrong, just point them out — I'll fix them all in one pass and update the rules.

## 场景 3:客户问"拿不准的邮件你怎么处理?"

**中文:**
我设了置信度门槛:系统只有足够确定时才自动处理,没把握的邮件一律不动,集中放在"待您确认"清单里,您扫一眼点一下就行。所以任何重要或模糊的邮件,最终决定权都在您手上——系统只自动处理那些明显是广告和通知的。

**English:**
The system only acts automatically when it's highly confident. Anything uncertain is never touched — it goes into a "needs your review" list where you just glance and click. So every important or ambiguous email ends with a human decision: yours. It only auto-handles things that are clearly newsletters or notifications.

## 场景 4:客户问"为什么不用 Gmail 自带的标签?"

**中文:**
Gmail 的标签只看发件人类型(社交/推广),不读内容,所以您的考试确认、交易记录会被误扔进"推广"。我的方案是读每一封邮件的内容,按您自己定的规则分类——对您重要的操作提醒(比如提现成功、订单确认)会被稳妥保留并标记,而不是和广告混在一起。

**English:**
Gmail's tabs only sort by sender type (Social/Promotions) — they don't read the content, which is why your exam confirmations or transaction alerts can end up filed as promotions. My approach reads the actual content of every email and classifies by rules you define — so what matters to you, like withdrawal alerts or order confirmations, is kept and flagged properly instead of mixed in with ads.
